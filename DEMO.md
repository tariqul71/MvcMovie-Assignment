# MvcMovie Project Demo

## 1. Start PostgreSQL
Open Docker Desktop and run:
docker start mvc-postgres

## 2. Run the Application
dotnet run --launch-profile http

## 3. Demonstrate MVC Features
- View the movie list
- Create a new movie
- Edit an existing movie
- Delete a movie
- Search for movies

## 4. Demonstrate Swagger API
Open http://localhost:5085/swagger/index.html

Show the GET, POST, PUT, and DELETE endpoints.
